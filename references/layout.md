# 版式规则与渲染核对

## 试卷（A4，2.4 cm 版心，17.8→16.2 cm 文本宽）

- 页眉：左侧 `绝密★启用前`（9 pt 加粗）+ 右侧 `试卷类型：A ｜ 科目代码：…`，下边一条 0.75 pt 横线。**用 2 列表格实现右对齐**，不要用制表位——LibreOffice 对 Header 样式自带的居中/右制表位会插一脚，右端对不齐。
- 标题：19 pt 黑体加粗 / 15.5 pt 副标题 / 10 pt 信息行 / 考生信息行。
- 注意事项：1×1 黑色细边框表格，9 pt，首条加粗。
- 选择题：题干 + 4 行 2 列（A/B 一行、C/D 一行）无边框表格，列宽各 8.1 cm；题干 `keep_with_next`，选项表第一行 `keep_with_next`，防止题干与选项被拆页。
- 非选择题：题干段落，行距 1.25，段前段后 9–14 pt 按题型递增，视觉上给手写留白。
- 页脚：`第 X 页（共 N 页）`，PAGE + NUMPAGES 域。

## 答题卡（A4，1.6 cm 边距）

- 顶部/底部黑白定位条：44 格 × 0.42 cm，负缩进 −1.6 cm 出血，模拟扫描定位带。
- 考生信息：2 列表格；左列姓名/考场号/座位号手写线 + 12 格准考证号方格（内框线要开）；右列红虚线"贴条形码区"。
- 缺考标记行 + 注意事项框（左竖排"注/意/事/项"）。
- 选择题：黑框容器，标题行合并单元格，题号按 `choice_per_row` 排布 `1　[A]　[B]　[C]　[D]`。
- 非选择题：每题一个黑色 1.5 pt 边框、`cantSplit` 的单元格，题号在左上，行内点线 0.92 cm 行距。
- 页脚：红框提示条 + `科目 第 X 页 共 N 页`（NUMPAGES 域，页数自适应）。

## 渲染核对清单

```bash
"<node>" "<libreoffice-kit-cli>" render --input out/xxx.pdf --output-dir .preview --pages "1,3"
```

1. 第 1 页：页眉右端是否贴齐横线；标题三行是否居中；注意事项框是否完整；选择题 A/C 是否左对齐成两栏。
2. 中间页：题干与选项是否被拆页；分区标题是否孤零零落在页底（给标题加 `keep_with_next`）。
3. 最后一页：是否只剩一两行（说明留白失衡，调段前段后或答题行数）。
4. 答题卡：定位条是否在页边、答题框是否整块不跨页、`共 N 页` 是否与实际一致。

## 常见症状 → 处理

| 症状 | 原因 | 处理 |
|---|---|---|
| 整页塌陷 / 出现 12 页空白 | 表格存在重复 `w:tblW`/`w:tblLayout` | `table_width()` 复用已有节点，不要 `append` |
| 答题横线只剩最外两条 | 相邻段落边框被合并 | 逐段加底边框并让颜色奇偶微差（`_ruled`） |
| 答题框被拆到两页 | 行未设 `cantSplit` | `no_split(row)` |
| 中文变黑体/宋体以外的字体 | 只设了 `rFonts.ascii` | `set_font` 里同时设 `w:eastAsia` |
| 封面页数对不上 | 静态写死 | 导出 PDF 后按 `/Type /Page` 计数回写重建（脚本内置） |
